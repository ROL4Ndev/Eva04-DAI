# Evaluación 4 - Desarrollo de Aplicaciones en Internet

Sistema web para la gestión de videojuegos desarrollado en PHP nativo con PDO y MySQL.

## Funcionalidades
- Listado de videojuegos con su respectiva consola.
- Búsqueda de videojuegos por nombre mediante POST.
- Edición de registros (nombre, consola, precio y stock).

## Tecnologías
- PHP
- MySQL
- PDO
- Bootstrap 5
