# Evaluación 4 - Desarrollo de Aplicaciones en Internet

Sistema web para la gestión de videojuegos desarrollado en PHP nativo con PDO y MySQL[cite: 1].

## Funcionalidades
- Listado de videojuegos con su respectiva consola[cite: 1].
- Búsqueda de videojuegos por nombre mediante POST[cite: 1].
- Edición de registros (nombre, consola, precio y stock)[cite: 1].

## Tecnologías
- PHP
- MySQL
- PDO
- Bootstrap 5
